# Scrcpy Dock v1.2.8

Windows 免安装版。

## 相对 GitHub v1.2.7 的变化

### 终端标签栏

- 标签增加序号徽章和独立强调色，左侧色条同步显示。
- 标签标题显示“终端 N · 版本”，未连接时也容易区分。
- 当前终端使用实心序号徽章、强调色边框和更深底色。
- 去掉底部难操作的横向滚动条。
- 标签栏右侧增加左右滚动按钮：
  - 每次滚动约一个标签宽度。
  - 到达左端或右端时对应按钮自动禁用。
- 增加“所有终端”按钮，弹出当前所有终端列表，可直接切换。
- 保留鼠标滚轮左右滚动。
- 标签拖拽排序继续可用。

### 修复

- 识别 scrcpy 的 `Device disconnected`、`Could not send keep alive`、`device offline` 等断连日志。
- 设备断连后立即标记“设备已断开”，清理残留 scrcpy 进程，无需先点终止即可重连。
- 关闭或重排终端后，页头与标签序号保持一致。
- 标签数量增加后内容宽度不扩展、无法滚动。
- 刷新标签栏时旧标签短暂残留。

## 使用

解压后运行 `ScrcpyDock.exe`。
