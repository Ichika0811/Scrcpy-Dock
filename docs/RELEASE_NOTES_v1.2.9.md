# Scrcpy Dock v1.2.9

Windows 免安装版。

## 相对 GitHub v1.2.8 的变化

### 稳定性

- 修复 Windows 任务管理器 / 文件属性中的进程描述显示为 `Scrcpy Dock 鈥?multi-terminal scrcpy manager`。
- 可执行文件描述统一为 `Scrcpy Dock`。
- 增加 ADB 设备列表轮询兜底：scrcpy 未输出断连日志时，连续两次发现当前设备不在线也会标记为“设备已断开”。
- 单实例名固定为 `ScrcpyDock.Instance`，并为配置写入增加 Windows 文件锁，避免多版本并发写入配置。

### 下载与扫描

- scrcpy 版本下载增加实时进度、取消按钮和取消后的临时文件清理。
- 全端口扫描改为分批提交，支持中途停止；停止后不应用不完整结果。

### 终端与日志

- 终端日志自动清理：默认保留 14 天，总大小上限 100 MB；可在“IP 与 ADB 设置”中调整。
- 终端标签颜色按序号动态生成，不再限制为 8 个。
- “所有终端”改为可搜索的切换器，支持按编号、版本或地址过滤。
- 增加 `Ctrl+1` 到 `Ctrl+9` 快速切换前 9 个终端。

### 维护

- 新增版本号同步脚本；构建前自动同步 `version_info.txt`、README 和发布文档。
- 后台任务运行器拆分到 `app/ui/tasks.py`，主窗口不再直接管理线程和进度对话框。

## 使用

解压后运行 `ScrcpyDock.exe`。
