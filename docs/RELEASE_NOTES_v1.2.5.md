# Scrcpy Dock v1.2.5

Windows 免安装版。

## 更新

- 左栏 scrcpy 版本图标改为按版本颜色区分的 Android 头像。
- 终端页头、空闲页、无终端页统一使用新应用图标。
- 关于页图标改用高分辨率 PNG，修复应用内旧图标。
- exe 图标重新嵌入。
- 保留以下既有能力：
  - 多 scrcpy 版本识别与一键连接
  - 1–65535 全端口扫描和 ADB 握手过滤
  - Docker 发布端口合并与无线 ADB 设备自动导入
  - 多终端并行、原生 scrcpy 窗口标题 `IP:端口 设备名`
  - 可交互命令终端：历史、粘贴、复制、Ctrl+C 中断
  - 可收起 IP 端口分组
  - 关于 / 版本信息页（F1）

## 使用

解压后运行 `ScrcpyDock.exe`。需要自行准备至少一个 scrcpy 版本目录，项目不附带 scrcpy / ADB 二进制。
